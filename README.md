# CodeQuest-X 🚀

C Programming Practice Platform

CodeQuest X is an interactive C programming practice platform designed to help beginners improve their coding skills.

Features

- Interactive coding challenges
- Basic automatic answer evaluation
- Score tracking
- Multiple programming topics
- Answer explanations

Technologies Used

- C Programming
- Standard C Libraries

Concepts Used

- Functions
- Strings
- File Handling
- Control Flow

Project Objective

To make C programming learning simple, interactive and interesting.
